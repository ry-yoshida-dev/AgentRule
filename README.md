# AgentRule

## Overview

Shared coding rules for AI coding agents, synchronized across machines with Git.

## Components

| Component | Description |
|---|---|
| [general.md](general.md) | Rules that apply to all work. Always read this file. |
| [language/](language/README.md) | Rules each programming language must follow (e.g., Python, TypeScript, Swift). |
| [framework/](framework/README.md) | Rules for building applications with a specific framework (e.g., React, SwiftUI). |
| [config/](config/README.md) | Rules for project configuration files (e.g., `pyproject.toml`). |
| [ui/](ui/README.md) | Guidelines to consider when building user interfaces (e.g., web, mobile). |

## Usage

Agents read [general.md](general.md), then follow the Components tables to the files relevant to the task.
