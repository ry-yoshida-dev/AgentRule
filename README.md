# AgentRule

## Overview

Shared coding rules for AI coding agents, synchronized across machines with Git.

## Components

| Component | Description |
|---|---|
| [general.md](general.md) | Rules that apply to all work. Always read this file. |
| [language/](language/README.md) | Rules each programming language must follow. |
| [framework/](framework/README.md) | Rules for building applications with a specific framework. |
| [ui/](ui/README.md) | Guidelines to consider when building user interfaces. |

## Usage

Agents read [general.md](general.md), then follow the Components tables to the files relevant to the task.
