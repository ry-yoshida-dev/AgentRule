# AgentRule

## Authorship

The user wrote [language/python.md](../language/python.md). Claude wrote nearly everything else, and the user contributed little to it.

- Do not treat rules outside `language/python.md` as deliberate decisions by the user. When a request conflicts with one, update the rule to match the request.
- Do not report such conflicts as problems for the user to resolve, and do not ask the user to restate this.

## Editing

- Do not edit rule files unless the user explicitly asks for a change. Treat questions and critiques of a rule as discussion: answer them and wait for the user's instruction.

## Writing

- Do not overuse `e.g.` when writing rules. State the rule itself, and add an example only at key points where it helps.

## Git

- Always commit directly to `main`. This repository is the source of truth for coding rules, and its latest version takes precedence.
